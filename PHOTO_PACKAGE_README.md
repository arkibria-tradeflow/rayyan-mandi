# Rayyan Mandi dish photography

This image pack includes real online photos of similar food, not real Rayyan product photography. It is intended for the client demo only. Original mutton feature photos remain unchanged.

Extract the archive to the repository root to preserve the assets/menu folder. Uploading a ZIP to GitHub as a file does not extract or display those images automatically.

See data/dish-image-mapping.csv for menu IDs and data/photo-credits.csv for attribution and license links. Respect the specified BY and SA conditions for attribution and derivative image use. All images were resized and cropped.
